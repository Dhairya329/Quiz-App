# 📚 Quiz App

An Android quiz application built using **Kotlin** and **XML** that challenges users with 25 mixed-topic multiple-choice questions. The app validates answers in real time, tracks user performance, and displays the final score with a trophy-based result screen.

## ✨ Features

* User name validation before starting the quiz
* 25 mixed-topic multiple-choice questions
* Real-time answer validation
* Automatic score calculation
* Simple and intuitive UI

## 🛠️ Tech Stack

* Kotlin
* Android Studio
* XML

## 🚀 Getting Started

1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle and run the app
